# 探索候補エリアの区画データ（areas/）の作り方

アプリの「地上げ → 地図 → 🎯 探索候補」が読む区画データを作るスクリプトです。
**事前に1回だけ**動かします（国勢調査は5年ごとなので、次は令和7年調査の小地域データが出た時）。

## 手順

```
pip install pyshp shapely
python scripts/build-area-geojson.py
npm run build        # dist/areas/ にコピーされることを確認
```

- ダウンロードは**全部スクリプトが自動で**行います。手作業はありません。
- 作業ファイルは一時フォルダ（`%TEMP%\hikari-area-build`）に置き、2回目以降は再ダウンロードしません。
- 出力は `areas/index.json`（市区町村の一覧）と `areas/<市区町村コード>.geojson`（例 `11301.geojson`＝伊奈町）。

## 使っているデータ（e-Stat 統計GIS・令和2年国勢調査・小地域（町丁・字等別）・埼玉県）

| 中身 | e-Stat の番号 | 使い方 |
|---|---|---|
| 境界（形） | 境界データ `A002005212020`（世界測地系・緯度経度・Shape） | 区画の形。川・湖（水面調査区）は除く |
| 年齢別人口 | `T001082` 男女，年齢（5歳階級及び3区分）別人口 | 高齢化率＝65歳以上 ÷（15歳未満＋15〜64歳＋65歳以上） |
| 住宅の建て方 | `T001086` 住宅の建て方別主世帯数 | 一戸建て割合＝一戸建 ÷ 主世帯数 |

- 人口・世帯数は境界データに入っている値（JINKO / SETAI）を使います。
- 人数が少なく数字が伏せられている区画（秘匿）は、合算先の区画の割合を使います。
- 同じ名前の区画が市内に複数ある時（大字が字ごとに分かれている）は「大字小室①②…」と番号を付けます。

## 軽くするための工夫

- 形を簡略化（許容誤差 0.00007度≒7m、`--tol` で変更可）し、座標は小数5桁に丸めています。
- 市区町村ごとにファイルを分け、アプリは選んだ市町村の分だけ読みます（起動時には読みません）。
- 2026-10-16 時点：72市区町村・5,979区画・合計 約4.7MB、最大は秩父市 約250KB。
