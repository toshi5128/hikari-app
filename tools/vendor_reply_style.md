# 業者への返事の文体メモ（下田さん）

reply_drafter.py が業者（買取業者）への返事を書くときに、毎回そのまま AI に渡す。
「こんな雰囲気で」の指示でよく出るものは、ここに1行ずつ足していく（育てるメモ）。

- 署名は書かない（送信時に自動で付く）
- 「ご都合いかがでしょうか」は使わない
- 内見・現地確認をお願いするときは「伺いたいと思うのですが」を使う
- 内見・現地確認の話になったら、キーボックスの有無を必ず確認する（こちらから聞く／相手に伝える）
- 相手が「値下げは難しい」「この金額が限界」と言ってきたときは、相手の事情に配慮した言い回しにする（責めない・押しすぎない）
- 業者どうしのやり取りなので、丁寧だが簡潔に。長い前置きはしない
